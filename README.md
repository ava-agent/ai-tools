## 简介

AI Tools Handbook 是一个全面的 AI 开发工具选型指南，基于实战经验整合了 30+ 款工具的深度评测数据。涵盖 AI IDE、大语言模型、插件扩展等多个类别，提供 SWOT 分析、使用心得和最佳实践建议。

## 特性

- **深度评测** - 基于 10+ 份调研文档的实战数据
- **SWOT 分析** - 每个工具的优势、劣势、机会、威胁分析
- **智能筛选** - 按类别、标签、开发者快速筛选
- **双版本支持** - 区分国内版(CN)和国际版(Global)
- **响应式设计** - 完美适配桌面和移动设备

## 快速开始

```bash
# 克隆仓库
git clone https://github.com/ava-agent/ai-tools.git
cd ai-tools/website

# 安装依赖
npm install

# 开发模式
npm run dev

# 构建生产版本
npm run build
```

## 技术栈

- Vue.js 3 - 前端框架
- Vite - 构建工具
- Tailwind CSS - 样式框架
- Pinia - 状态管理
- Vue Router - 路由管理
