### 可用命令

- `exec` - 非交互式执行
- `review` - 代码审查
- `login` - 管理登录
- `logout` - 删除认证凭据
- `mcp` - MCP 服务器管理（实验性）
- `mcp-server` - MCP 服务器（实验性）
- `app-server` - 应用服务器（实验性）
- `completion` - 生成 Shell 自动完成脚本
- `sandbox` - 沙箱命令执行
- `debug` - 调试工具
- `apply` - 应用最新的 git diff
- `resume` - 恢复之前的会话
- `fork` - 分支之前的会话
- `cloud` - Codex Cloud 任务浏览（实验性）
- `features` - 检查功能标志
- `help` - 显示帮助信息

### 推荐配置

复制配置示例到用户目录：

```bash

mkdir -p ~/.codex
cp config-example.toml ~/.codex/config.toml

# Windows
mkdir %USERPROFILE%\.codex
copy config-example.toml %USERPROFILE%\.codex\config.toml
```
