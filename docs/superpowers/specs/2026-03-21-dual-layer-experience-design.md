# AI 工具全书「双层体验」改造设计

## 定位

个人技术名片。核心场景：社交分享链接，对方 2-3 分钟浏览。需要在 5 秒内传达广度（125+ 工具全景），在 2 分钟内传达深度（实战经验和独到判断）。

## 设计原则

- 首页冲击力优先
- 个人洞察 > 参数信息
- 不删除已有功能，只调整入口层级
- 最小改动量，最大感知提升

---

## 一、新首页（替换现有 Home.vue）

### 1.1 Hero 区域（首屏）

全屏深色背景，居中布局：

- **主标题**：「AI 工具全书」
- **副标题**：基于真实项目经验的 AI 工具评测与选型指南
- **动态数字**（计数动画）：
  - `125+` 款工具深度评测
  - `7` 大类别全景覆盖
  - `500+` 条实战洞察
- **CTA 按钮**：「浏览工具全景」→ 平滑滚动到版图区

视觉风格：保持现有深色主题（#05051a 背景），数字用品牌绿色（#30d158）强调。

### 1.2 工具版图区（核心视觉）

交互式气泡图，125 个工具按 7 大类别聚合：

- **布局**：7 个类别区域，每个区域内工具以气泡形式排列
- **气泡大小**：映射 personalExperience.rating（评分越高越大）
- **气泡颜色**：映射 category（使用 categories.js 中已定义的颜色）
- **交互**：
  - 悬停：显示 tooltip（工具名 + 一句话 bestFor + 评分星标）
  - 点击：跳转 `/tool/:id` 详情页
- **类别标签**：每个聚类区域上方显示类别名和工具数量

技术方案：使用 CSS Grid + 绝对定位实现，不引入 D3.js 等重型库。气泡为圆形 div，使用 ToolLogo 组件渲染。

备选方案：如果气泡图实现复杂度过高，降级为分类卡片网格，每张卡片展示一个类别（名称 + 工具数 + 代表工具 logo），点击展开该类别的工具列表。

### 1.3 「我的推荐栈」区

3-5 个日常使用的工具组合，卡片式布局：

- **日常编码**：Cursor — "主力 IDE，Composer 跨文件重构是护城河"
- **复杂重构**：Claude Code — "超过 10 文件的改动切到 CLI，Agent 能力最强"
- **免费方案**：Trae + Gemini CLI — "零成本组合，1M 上下文做长文档分析"
- **视觉设计**：Midjourney + GPT-5 Image — "艺术风格 vs 文字渲染各有所长"

每张卡片：工具 Logo + 名称 + 一句个人洞察（引用样式）。

数据来源：新增 `src/data/recommendations.js`，手动维护 3-5 条推荐。

### 1.4 快速入口区

3 张入口卡片，水平排列：

| 入口 | 跳转 | 图标 | 描述 |
|------|------|------|------|
| 全景浏览 | `/tools`（原首页工具列表，改为独立路由） | Grid | 125+ 工具分类浏览与搜索 |
| 选型对比 | `/comparison` | Scale | 最多 4 款工具横向对比 |
| 工作流指南 | `/workflows` | Workflow | 6 套实战工作流模板 |

### 1.5 Footer

- 一行个人介绍："Kevin · AI 工具深度用户 · 持续更新中"
- GitHub 图标链接

## 二、工具详情页内容提权（修改 ToolDetail.vue）

### 信息优先级重排

调整区块顺序（从上到下）：

1. **工具头部**（不变）：Logo、名称、评分、开发者、访问按钮
2. **个人洞察卡片**（从底部提到第二位）：
   - 左侧 4px 品牌绿色边框
   - 半透明深色背景（rgba(48,209,88,0.04)）
   - 标题："实战洞察"
   - 内容：`personalExperience.insights`
   - 避坑列表：`personalExperience.pitfalls`（带警告图标）
3. **SWOT 分析**（不变）
4. **版本与定价**（从第二位下移到第四位）
5. **优劣势**（不变）
6. **相关工具**（不变）

### 视觉强调

个人洞察卡片使用区别于其他信息区块的样式，让浏览者一眼识别"这是作者的经验，不是官方信息"。

- 不做 SEO 优化
- 不做移动端特殊适配（保持现有 Tailwind 响应式）

## 八、成功标准

- 首屏 5 秒内能看到：工具数量、类别覆盖、个人品牌
- 2 分钟内能感受到：全景广度（版图区）+ 实战深度（推荐栈 + 详情页洞察）
- 导航清晰，核心路径不超过 2 次点击
- 无新增 npm 依赖，构建体积不显著增加
